Polestar 10 DB 복구

Polestar 10 DB를 복구가 필요할 경우 가이드입니다.

복구 시 현재 데이터가 삭제되므로 현재 데이터 백업이 필요할 경우 사전에 백업 후 진행하기를 권고합니다.

DB 복구는 데이터 무결성을 위해서 POLESTR 10을 중지하고 진행해야 합니다.

아래 스크립트를 실행하여 복구를 진행할 수 있습니다.

<table>
<thead>
<tr class="header">
<th>스크립트 실행</th>
<th>설명</th>
</tr>
</thead>
<tbody>
<tr class="odd">
<td><p># ./mongodb.sh restore</p>
<p>Select the mongodb volume to restore:</p>
<p>1 : polestar_mongodb-1-configdb</p>
<p>2 : polestar_mongodb-1-db</p>
<p>3 : polestar_mongodb-1-log</p>
<p>Select (number): 2</p>
<p>Restore volume : polestar_mongodb-1-db</p>
<p>Restore Volume mountpoint: /var/lib/docker/volumes/polestar_mongodb-1-db/_data</p>
<p>Enter the path of the backup file: ./backup/3/polestar_mongodb-1-db_backup_20241214111613.tar.gz</p>
<p>Restoring mongodb data will delete existing data.</p>
<p>Please verify the backup before proceeding.</p>
<p>Do you want to proceed with the restoration? (Y/n): y</p>
<p>Deleting existing data...</p>
<p>Restoring backup file to volume...</p>
<p>Restoration have been completed. [ok]</p></td>
<td><p>[파일 위치]</p>
<p>lucida-for-docker/polestar/bin</p>
<p>[실행 절차]</p>
<p>1. 복구할 몽고디비 볼륨 선택</p>
<p>2. 몽고디비 볼륨 디렉토리내의 데이터 파일 삭제</p>
<p>3. 복구 진행 및 완료</p></td>
</tr>
</tbody>
</table>
