Polestar 10 DB 백업

Polestar 10 DB를 백업이 필요할 경우 백업 가이드입니다.

DB 백업은 데이터 무결성을 위해서 POLESTR 10을 중지하고 진행해야 합니다.

아래 스크립트를 실행하여 백업을 진행할 수 있습니다.

<td>0</td>
<td>몽고디비 컨테이너 중지 여부 확인</td>
<td><p>몽고디비 컨테이너를 중지후 진행해야 합니다.</p>
<p>컨테이너가 기동중일 경우 아래와 같이 메시지 출력후 중지됩니다.</p>
<p>[예시]</p>
<p>There are running mongodb containers using the volumes.</p>
<p>- polestar-mongodb-1-1</p>
<p>You need to stop these containers for data consistency. [fail]</p></td>
</tr>
<tr class="even">
<td>1</td>
<td>백업 디렉토리 입력</td>
<td><p>데이터를 백업할 디렉토리를 입력합니다.</p>
<p>디스크 공간이 충분한 위치의 경로로 입력합니다.(절대/상대 경로 가능)</p>
<p>신규 디렉토리를 입력하면 생성할지를 물어보고 디렉토리를 생성하면서 진행할 수 있습니다.</p>
<p>참고로, 디렉토리 입력시 자동완성 기능이 동작합니다.(탭키)</p>
<p>[예시]</p>
<p>Enter the backup directory: ./backup/20241210</p>
<p>The backup directory does not exist. Do you want to create it? (Y/n): y</p></td>
</tr>
<tr class="odd">
<td>2</td>
<td>몽고디비 볼륨 목록중 선택</td>
<td><p>몽고디비 컨테이너가 데이터를 저장하는 볼륨을 검색하고 해당 볼륨목록을 출력합니다.( polestar_mongodb-initializer 제외)</p>
<p>목록중 백업할 볼륨을 선택합니다.</p>
<p>다중선택은 콤마분리로 가능하며, 다중선택시 각각 백업파일이 생성됩니다.</p>
<p>[예시]</p>
<p>List of mongodb volumes:</p>
<p>1 : polestar_mongodb-1-configdb</p>
<p>2 : polestar_mongodb-1-db</p>
<p>3 : polestar_mongodb-1-log</p>
<p>Select the volumes to backup (ex&gt; 2 or 1,2): 2</p></td>
</tr>
<tr class="even">
<td>3</td>
<td>백업 정보 출력</td>
<td><p>사용자가 선택한 백업정보들을 출력합니다.</p>
<p>백업볼륨, 백업크기, 백업우치, 디스크 여유공간을 확인할 수 있도록 관련정보를 출력합니다.</p>
<p>[예시]</p>
<p>Backup volumes: polestar_mongodb-1-db</p>
<p>Volume 'polestar_mongodb-1-db' size: 458M</p>
<p>Backup size: 457MB</p>
<p>Backup directory: /data/lucida/build/10.1.2/release/lucida-for-docker/polestar/bin/backup/20241210</p>
<p>Available space: 7.4T</p></td>
</tr>
<tr class="odd">
<td>4</td>

<p>Y/y : 백업진행</p>
<p>N/n : 백업중단</p>

<p>Do you want to proceed with the backup? (Y/n): y</p>

<p>미설치시에도 진행률 표시 없이 백업은 진행됩니다.</p></td>
