CUBRID 상세

CUBRID 상세 화면에서는 CUBRID의 성능 정보, 구성 정보를 확인할 수 있으며 세션 및 SQL 수행 이력을 상세 분석할 수 있습니다. 성능 메뉴에서는 카테고리(인스턴스, 세션(프로세스), SQL, 메모리, 로그, Broker, Volume)별로 성능을 확인할 수 있습니다. 구성 이력에서는 CUBRID 구성 정보(환경변수, Broker 구성, Volume 크기 등)의 변경 이력을 확인할 수 있으며 현황 정보에서는 환경변수, Broker 요약, Broker Status, Volume의 현재 시점 구성 정보를 확인할 수 있습니다. 설정 정보에서는 CUBRID 접속 정보를 수정하거나 역할 및 담당자 등을 설정할 수 있습니다. 세션 분석 메뉴를 통해 CUBRID에 수행된 세션의 이력을 분석할 수 있고 Top SQL 분석을 통해 CUBRID에 수행된 SQL 중 성능 지연이 발생된 SQL을 빠르게 찾고 분석할 수 있습니다. 마지막으로 SQL 성능 분석에서는 세션 이력정보에서 수집된 SQL의 성능 지표를 Scatter 차트에 표시하여 한눈에 실행된 SQL들의 성능을 확인하고 원하는 SQL을 선택하여 분석할 수 있습니다.

CUBRID 인스턴스 성능

CUBRID 인스턴스 성능 화면은 CUBRID 인스턴스의 전반적인 상태, 성능, 효율성 정보를 조회할 수 있는 화면입니다. 상단에 CUBRID 가용성, 서버 CPU 사용률, 서버 메모리 CPU 사용률 및 Master 프로세스와 Broker 프로세스 수가 표시되고 그 밑으로 CUBRID 주요 성능 지표에 대한 차트와 CUBRID Effciency(효율성) 지표 목록이 표시됩니다.

CPU 사용률/메모리 사용률 Area 차트

CUBRID Efficiency(효율성) 목록

CUBRID 효율성 지표 값을 통해 현재 CUBRID가 효율적으로 잘 운영되고 있는지 확인할 수 있습니다. 또한 효율성 지표를 통해 성능을 평가하고 문제를 진단하는데 유용하게 사용될 수 있습니다. 해당 지표 중 적중률 관련 지표들은 100%일때가 가장 효율적이라고 판단할 수 있으며 비율이 낮을수록 해당 지표의 효율성이 낮다고 판단할 수 있습니다. 특히 버퍼 캐시 적중률비율이 매우 낮다면 세션 및 SQL 분석을 통해 원인을 찾고 개선할 필요성이 있습니다.

CUBRID 세션(프로세스) 성능

CUBRID 세션 및 프로세스 관련 성능을 조회하는 화면입니다. 상단에 세션 사용률 및 세션 수 현황이 표시되며 하단에 세션 관련 지표의 라인차트와 누적 영역 차트가 표시되고 그 밑으로 현재 수행 중이거나 락이 발생된 세션들의 목록이 표시됩니다. 해당 화면에서는 추가적으로 “세션 상세 현황”을 볼 수 있는 화면으로의 이동을 제공하며 세션 상세 현황 화면을 통해 세션이 수행한 SQL 정보, “개별 세션 이력 조회”, “개별 SQL 이력 조회”가 가능합니다. “세션 상세 현황”, “개별 세션 이력 조회”, “개별 SQL 이력 조회”에 대한 상세 내용은 본 매뉴얼의 관련 절을 참조하세요.

세션 사용률 및 세션수 현황

현재 시점 CUBRID에 허용 가능 최대 세션수 및 연결 세션수, 세션 사용률, 액티브/블록/블로킹 세션수가 표시되며 연결 세션수 카드에 마우스 오버시 우측 상단에 표시되는 아이콘(![](./images/db-002/media/image12.png))을 선택하면 상세 세션 현황 화면으로 이동합니다. 상세 세션 현황 화면에서는 현재 접속된 모든 세션 목록을 조회하고 분석할 수 있으며 자세한 내용은 “세션 현황 화면”절에서 확인하실 수 있습니다.

![](./images/db-002/media/image13.png)

▶ \[그림6\] 세션 사용률 및 세션수 현황

총 세션수 누적 영역 차트

CUBRID 접속 세션수를 4가지 상태(Active/Idle/Blocking/Blocked)로 나누어 누적 영역 차트로 표시합니다. 각 범례를 멀티 선택하여 원하는 범례들 만을 보실 수 있습니다. 특히 전체 세션 대비 Active 세션이 많은 시간대나 Blocking, Blocked 세션수가 있는 시간대는 유의해서 살펴볼 필요가 있습니다.

현재 접속된 세션 중 Actvie 상태이거나 Blocking, Blocked 상태인 세션 목록을 표시합니다. 해당 목록을 통해 현재 수행중인 세션이나 블록 된 세션 정보를 확인할 수 있습니다. 보다 상세한 세션 현황 정보는 우측 상단 \[더보기\] 버튼을 클릭하여 세션 상세 현황 드로어에서 확인할 수 있으며 현지 시점 및 과거 수행된 세션 이력을 분석하고 싶다면 우측 상단 \[세션분석\] 버튼을 클릭하여 나오는 세션분석 화면에서 상세 분석하실 수 있습니다.

| SQL ID  | 해당 트랜잭션(세션)에서 수행중인 쿼리의 ID값입니다. ID값은 고유 값으로 해당 쿼리문을 대표하며 KILL 트랜잭션 명령에서 식별키로 사용되는 값입니다.                                          |
| 수행시간    | 해당 트랜잭션(세션)에서 현재 실행중인 쿼리의 수행 시간입니다. 단위는 초입니다.                                                                                   |
| 트랜잭션 시간 | 트랜잭션이 유지된 시간입니다. 단위는 초입니다. 만약 쿼리문 없이 트랜잭션 시간이 증가한다면 트랜잭션을 종료하지 않고 있는 Idle 트랜잭션 일 수 있습니다. 이 경우 원인을 찾고 해당 트랜잭션(세션)을 종료할 필요가 있습니다. |
| 블로킹 TID | 해당 트랜잭션이 대기중일 경우 대기를 발생시킨 트랜잭션 TID가 표시됩니다. 블로킹 TID간의 관계를 좀 더 명확히 보고자 한다면 세션현황이나 세션 이력 화면 하단 Lock Tree를 조회해 볼 수 있습니다.            |

1.  구성 변경 현황 바 차트에서 비교하고자 하는 시점의 바를 클릭

Lock Tree

CUBRID에 락 세션이 발생되면 Lock Tree 목록에서 해당 락 세션들을 확인할 수 있습니다. Lock Tree에서는 락을 유발한 세션(블로킹 세션)을 부모로 하고 해당 락으로 인해 블록 된 세션을 자식으로 하는 트리 형태로 목록을 표시합니다. 부모 락 세션을 기준으로 해당 트리를 접거나 펼쳐 볼 수 있으며 SQL ID 컬럼에 있는 SQL ID를 선택하면 하단에 해당 세션의 SQL을 표시합니다. SQL Text 창의 우측 상단에 SQL문 포메팅 토글 버튼을 통해 SQL을 포메팅 해서 볼 수 있습니다. 또 그 옆에 상세보기 버튼을 클릭하면 SQL Text 상세 드로어가 표시되며 해당 드로어 화면에서 SQL에 대한 상세 성능 이력 정보를 확인할 수 있습니다. 자세한 내용은 “개별 SQL 이력 보기(SQL Text 상세 드로어)”절을 참조하세요.

기간별 Top SQL(바차트)

타임 셀렉터 기간에 해당하는 SQL별 세션 수를 누적 바차트로 표시합니다. 바차트의 간격은 기간별로 달라지며 바 차트 개수는 최대 60개까지 표현됩니다. 바차트를 1개 선택하면 해당 시점의 바차트만 활성화되고 하단 세션 목록은 바 차트 1개에 해당하는 기간의 세션만 표시됩니다. 따라서 상단에 SQL 목록에서 SQL을 선택하고 바차트에서 특정 바 1개를 선택한다면 특정 시점에 선택한 SQL을 수행한 세션만 세션 목록에서 필터링하여 조회할 수 있습니다. 마지막으로 바차트 우측 상단 선택 범례만 표시 토글 버튼을 통해 상단 Top SQL 목록에서 선택한 1개의 대상 범례만 바차트에 표시할 수 있습니다.

Top SQL 이력 분석 기능을 통해 CUBRID에서 수행된 SQL들 중에 성능 이슈가 있는 SQL등을 4가지 관점(SQL, 사용자, 호스트, 프로그램)으로 분석해 볼 수 있습니다. SQL의 다양한 성능(세션수, 평균 수행시간, 총 수행시간, 최대 수행시간) 기준으로, 최대 30개의 Top SQL을 검색하여 분석할 수 있습니다.

SQL탭

개별 SQL 단위로 성능 지연이 발생한 SQL을 분석할 수 있는 화면입니다. 다양한 성능 지표로 Top SQL을 조회하고 해당 Top SQL의 수행이력을 조회해 볼 수 있습니다. 또한 개별 SQL을 선택하여 한 SQL에 대한 상세 이력 분석이 가능합니다.

SQL 분포도

SQL 분포도 타이틀 옆의 콤보 박스를 통해 표시되는 지표를 트랜잭션 시간으로 변경 가능하며 우측 상단 표시조건을 변경하여 특정 수행 시간 이상 또는 이하인 SQL 만을 표시할 수 있습니다. 또한 특정 SQL ID, 사용자, 프로그램, 호스트를 선택하여 해당 대상 SQL만을 필터링하여 분석할 수 있습니다. 그리고 차트 내에서는 마우스로 원하는 영역을 드래그 하여 선택하면 해당 영역에 해당하는 SQL 이력 정보만 SQL 상세 목록에 표시됩니다.
