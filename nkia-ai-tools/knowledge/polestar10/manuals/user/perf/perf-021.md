윈도우 성능카운터 감시 추가 절차

▶ \[그림5\] 윈도우 성능카운터 감시 삭제

윈도우 성능카운터 감시 삭제 절차

1.  윈도우 성능카운터 감시 목록에서 삭제할 윈도우 성능카운터 선택 (다수 선택 가능)

2.  윈도우 성능카운터 감시 목록 우측 상단의 \[삭제\] 버튼 클릭

윈도우 성능카운터 감시 일괄 추가

윈도우 성능카운터 감시 설정 정보를 CSV 형식으로 입력하여 다수의 윈도우 성능카운터 감시를 일괄 등록할 수 있습니다.

\[등록된 설정 다운로드\]를 통해 등록되어 있는 윈도우 성능카운터 감시 설정 정보를 CSV 파일로 다운로드하고, 이 CSV 파일을 활용하여 기존 윈도우 성능카운터 감시 설정을 일괄 업데이트 할 수 있습니다.

윈도우 성능카운터 감시 설정 정보를 저장한 CSV 파일을 업로드하고 \[검증\] 버튼을 클릭하면 CSV 파일 데이터의 유효성을 검사하여 등록 진행 가능 여부를 판별합니다. 하나라도 잘못된 설정이 포함되어 있는 경우 일괄 등록을 진행할 수 없습니다. 이 경우, ‘검증 결과’ 필드를 참고하여 설정 오류를 수정하고 다시 검증을 진행하시기 바랍니다.

▶ \[그림7\] 윈도우 성능카운터 감시 일괄 추가 – 검증 및 업로드 설정 목록

윈도우 성능카운터 감시 일괄 추가 절차

1.  윈도우 성능카운터 감시 목록 우측 상단의 \[일괄 추가\] 버튼 클릭

2.  \[등록된 설정 다운로드\] 버튼 클릭

3.  다운로드 받은 CSV 파일을 열고, 기존 등록되어 있는 윈도우 성능카운터 감시 설정을 참고해서 신규 윈도우 성능카운터 감시 설정 추가

4.  CSV 파일에 있던 기존 윈도우 성능카운터 감시 설정 삭제

5.  일괄 추가 드로어에서 CSV 파일 업로드하고 \[검증\] 버튼 클릭

6.  ‘업로드 설정 목록’에서 결함 유무 확인하고, 결함이 없는 경우 \[저장\] 버튼 클릭
