장비 정보

파일 감시 항목을 등록할 장비를 1대 이상 선택합니다. 장비 목록에는 사용자가 ‘쓰기’ 이상의 권한을 가지고 있는 서버만 표시되며, 태그 필터를 사용해 원하는 대상 장비를 상세 검색할 수 있습니다.

파일 감시 추가 절차

1.  파일 감시 목록 우측 상단의 \[추가\] 버튼 클릭

2.  기본 정보, 장비 정보, 설정 정보를 입력하고 \[저장\] 버튼 클릭

파일 성능 정보 조회

파일 감시 목록에서 ‘이름’ 필드를 클릭하여 등록한 파일 감시의 성능 정보를 조회합니다. 파일 감시 설정 정보에 따라 특정 파일의 성능 정보를 확인할 수 있습니다.

파일 감시 수정

파일 감시 목록에서 ‘설정’ 필드를 클릭하여 등록한 파일 감시의 설정 정보와 역할 및 권한 설정을 수정할 수 있습니다. 파일 감시의 기본 권한은 서버 장비의 권한을 따르므로 ‘상속’ 옵션이 활성화되어 있습니다. ‘상속’ 옵션을 비활성화하면 파일 감시에만 적용되는 전용 권한을 설정할 수 있습니다. 모든 필수 항목을 입력해야 \[저장\] 버튼이 활성화됩니다.

▶ \[그림5\] 파일 감시 삭제

파일 감시 삭제 절차

1.  파일 감시 목록에서 삭제할 파일 선택 (다수 선택 가능)

2.  파일 감시 목록 우측 상단의 \[삭제\] 버튼 클릭

파일 감시 일괄 추가

파일 감시 설정 정보를 CSV 형식으로 입력하여 다수의 파일 감시를 일괄 등록할 수 있습니다.

\[등록된 설정 다운로드\]를 통해 등록되어 있는 파일 감시 설정 정보를 CSV 파일로 다운로드하고, 이 CSV 파일을 활용하여 기존 파일 감시 설정을 일괄 업데이트 할 수 있습니다.

파일 감시 설정 정보를 저장한 CSV 파일을 업로드하고 \[검증\] 버튼을 클릭하면 CSV 파일 데이터의 유효성을 검사하여 등록 진행 가능 여부를 판별합니다. 하나라도 잘못된 설정이 포함되어 있는 경우 일괄 등록을 진행할 수 없습니다. 이 경우, ‘검증 결과’ 필드를 참고하여 설정 오류를 수정하고 다시 검증을 진행하시기 바랍니다.

▶ \[그림7\] 파일 감시 일괄 추가 – 검증 및 업로드 설정 목록

파일 감시 일괄 추가 절차

1.  파일 감시 목록 우측 상단의 \[일괄 추가\] 버튼 클릭

2.  \[등록된 설정 다운로드\] 버튼 클릭

3.  다운로드 받은 CSV 파일을 열고, 기존 등록되어 있는 파일 감시 설정을 참고해서 신규 파일 감시 설정 추가

4.  CSV 파일에 있던 기존 파일 감시 설정 삭제

5.  일괄 추가 드로어에서 CSV 파일 업로드하고 \[검증\] 버튼 클릭

6.  ‘업로드 설정 목록’에서 결함 유무 확인하고, 결함이 없는 경우 \[저장\] 버튼 클릭
