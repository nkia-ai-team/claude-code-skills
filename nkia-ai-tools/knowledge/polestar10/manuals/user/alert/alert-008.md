관리 대상 추가

전체구성에서 \[관리 대상 추가\] 버튼을 클릭하여 관리 장비 타입별로 신규 장비를 등록할 수 있습니다. 관리 대상 메뉴에는 각 관리 장비 타입을 선택하여 신규 장비 등록 절차를 시작합니다.

관리 대상 - 애플리케이션

관리 대상 메뉴에서 \[애플리케이션\]를 선택하면 애플리케이션 에이전트가 설치된 등록 대기 상태의 에이전트 목록을 확인할 수 있습니다. 관리 대상 메뉴에 녹색으로 표시되는 숫자는 POLESTAR에 연결된 지 24시간이 경과하지 않은 신규 애플리케이션 개수를 의미합니다. 등록 대기 애플리케이션 에이전트 목록 우측 상단에는 등록 실패 이력이 있는 애플리케이션 에이전트 개수가 표시됩니다.

관리 대상 – 애플리케이션 등록

등록 대기 에이전트 목록에서 애플리케이션을 선택하여 등록할 수 있습니다. 등록 시 공통 알람 정책과 서비스태그를 설정할 수 있습니다. 애플리케이션 에이전트의 경우 수집정책, 관리 상태는 초기 지정 값을 사용합니다.

애플리케이션 등록 절차

1.  등록 대기 애플리케이션 목록에서 등록할 애플리케이션 선택 (다수 선택 가능)

2.  화면 우측 하단의 \[관리 대상 등록\] 버튼 클릭

3.  필수 항목 설정 (공통 알람 정책, 서비스 태그)

4.  등록할 애플리케이션 선택 (다수 선택 가능)

5.  화면 우측 사단의 \[등록\] 버튼 클릭

관리 대상 – 애플리케이션 등록 – 일괄 변경

등록 대기 애플리케이션 목록에서 전체 대상으로 설정값을 일괄적으로 변경할 수 있습니다.

![](./images/alert-008/media/image15.png)

▶ \[그림 \] 관리 대상 - 애플리케이션 등록 – 일괄 변경

설정값 일괄 변경 절차

1.  페이지 우측 상단의 일괄변경 아이콘을 클릭

2.  변경할 항목을 체크 후, 선택 상자에서 데이터를 선택

3.  우측 하단의 \[확인\] 버튼 클릭

4.  그리드에 있는 모든 대상의 항목이 일괄변경

관리 대상 – 애플리케이션 삭제

등록 대기 상태의 애플리케이션을 삭제할 수 있습니다. 삭제한 등록 대기 애플리케이션은 삭제 후 바로 다시 등록 대기 상태 장비로 재등록되어 등록 대기 목록에 추가됩니다. 따라서 애플리케이션을 완전히 삭제하려면 애플리케이션 에이전트 옵션 또는 모듈을 애플리케이션에서 제거해야 합니다. 아래 노트를 참고하여 애플리케이션을 삭제하면 원치 않는 애플리케이션이 등록 대기 목록에 추가되는 일을 방지할 수 있습니다.

애플리케이션 삭제 절차

1.  등록 대기 애플리케이션 목록에서 삭제할 서버 선택 (다수 선택 가능)

2.  등록 대기 애플리케이션 목록 우측 상단의 \[삭제\] 버튼 클릭

3.  삭제 확인 메시지창에서 \[확인\] 버튼 클릭

관리 대상 – 데이터베이스

관리 대상 메뉴에서 \[데이터베이스\]를 선택하면 데이터베이스 등록 대기 목록 화면이 표시됩니다. 등록 대기 목록 상단에 데이터베이스 등록(![](./images/alert-008/media/image17.png)) 버튼을 클릭하면 데이터베이스 등록 드로우가 표시됩니다. 해당 드로우 화면을 통해 데이터베이스 등록 대기 목록에 신규 데이터베이스를 추가를 할 수 있습니다. 이후 등록 대기 목록에 추가된 데이터베이스는 우측 하단 관리 대상 등록 버튼을 이용하여 실제 관리 대상 데이터베이스로 등록할 수 있습니다.

![](./images/alert-008/media/image18.png)

데이터베이스 등록 대기 목록에 추가 절차

1.  데이터베이스 등록 대기 목록 상단에 데이터베이스 추가(![](./images/alert-008/media/image17.png)) 버튼을 선택

2.  데이터베이스 등록 드로우에서 각종 연결정보 입력 및 이력 정보 수집 여부 선택

3.  데이터베이스 등록 드로우 하단 추가 버튼 선택

관리 대상 – 데이터베이스 등록 드로우

데이터베이스 등록 대기 목록 상단에 데이터베이스 등록(![](./images/alert-008/media/image17.png)) 버튼을 클릭하면 표시되는 드로우 화면에서 데이터베이스 등록에 필요한 기본 접속 정보 및 데이터베이스별 상세 설정을 할 수 있습니다. 설정 후 저장 버튼을 클릭하면 데이터베이스 등록 대기 목록에 등록 드로우에 설정한 데이터베이스가 추가됩니다.
