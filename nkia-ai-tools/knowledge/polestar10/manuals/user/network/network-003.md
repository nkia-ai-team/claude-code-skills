네트워크 상세

네트워크 상세 화면에서는 네트워크의 성능 정보, 구성 정보를 확인할 수 있으며 인터페이스를 비롯하여 장비의 트래픽 정보를 상세 분석할 수 있습니다. 성능 메뉴에서는 카테고리(인터페이스, CPU, 메모리, 모듈)별로 성능 정보를 확인할 수 있습니다. 구성 메뉴에서는 카테고리(구성 이력, 설정 정보)별로 구성 관련 정보를 확인할 수 있습니다.

구성 이력 화면에서는 네트워크 구성 정보(호스트, IP주소, 호스트명, 제조사 등)의 변경 이력과 현황 정보를 확인할 수 있습니다. 설정 정보 화면에서는 네트워크 연결 정보를 비롯한 기본 설정 정보와 역할 및 권한, 리소스 담당자, 추가 정보 등을 조회하거나 변경 가능합니다. 네트워크 장비에 설정되어 있는 알람 정보와 수집 정책을 조회할 수 있으며, 성능/구성 데이터 최근 수집 시간을 조회하고 즉시 실행을 통한 즉시 수집 기능을 제공합니다. 현황 정보 화면에서는 네트워크 장비의 인터페이스, TCP 연결 테이블, ARP 테이블, Route 테이블, MAC 주소 테이블 정보를 확인할 수 있습니다. 단, 인터페이스의 경우 관리대상으로 등록된 인터페이스의 구성 정보만 표시합니다.

분석 메뉴에서는 SLB 분석 카테고리를 통해 네트워크 장비의 LB 매핑 정보와 가상서버, 물리서버 상세 정보를 확인할 수 있습니다. SLB 분석 메뉴는 LB 기능을 지원하는 네트워크 장비에서만 사용 가능합니다. LB 기능을 지원하지 않을 경우 SLB 분석 메뉴가 화면에 나타나지 않습니다.

네트워크 시스템 성능

네트워크 시스템 성능 화면은 네트워크 장비의 전반적인 상태와 성능, 구성 정보를 조회할 수 있는 화면입니다. 상단 요약 카드 형식의 영역에서는 네트워크 구성 정보(장비명, IP 주소, 제조사(모델))와 네트워크 성능 정보(SNMP 상태, ICMP 상태, CPU 사용률, 메모리 사용률)가 표시됩니다. 아래에는 네트워크 인터페이스의 구성 정보와 현재 상태를 조회할 수 있는 컴포넌트가 위치합니다. 오른쪽 영역의 상단에는 CPU/메모리 사용률 차트가, 그 밑으로 팬/파워/온도의 상태 정보를 나타내는 컴포넌트가 표시됩니다. 제일 하단에는 네트워크 장비의 주요 성능 지표인 가동일수, RTT에 대한 차트가 표시됩니다.

인터페이스

네트워크 장비의 인터페이스 구성과 상태를 한 눈에 볼 수 있도록 표현한 컴포넌트입니다. 상단에는 전체 인터페이스를 대상으로 물리 포트와 가상 포트의 개수와 관리상태 별 인터페이스 수를 표시합니다. 그 밑으로 전체 물리 포트의 상태를 표시하는 포트 맵이 위치합니다. 이를 통해 네트워크 장비의 인터페이스 전체 구성과 개별 상태를 한눈에 파악할 수 있습니다.

인터페이스 성능

인터페이스 성능 화면은 네트워크 장비의 인터페이스에 대해 상태와 성능 정보를 조회하는 화면입니다. 상단에 주요 성능지표에 대한 인터페이스 Top5 정보가 차트로 표시되며 그 밑으로 네트워크 인터페이스 별 성능 정보가 최대 10개까지 목록으로 표시됩니다. 목록 옆의 파란색 숫자는 네트워크 장비의 전체 인터페이스 수를 의미하며, 더보기를 클릭하여 전체 인터페이스 분석 화면으로 이동할 수 있습니다.

전체 인터페이스

전체 인터페이스 화면은 네트워크 장비의 모든 인터페이스에 대해 성능 정보를 상세하게 조회하고 분석하는 화면입니다. 상단에는 조회시간동안 수집된 전체 인터페이스의 트래픽 Rx, 트래픽 Tx 정보를 전체 인터페이스 차트로 표시합니다. 그 밑으로 가장 마지막에 수집된 전체 인터페이스의 성능 정보들을 목록으로 표시합니다. 전체 인터페이스 차트의 특정 시점을 클릭하면 해당 시점에 대한 인터페이스 목록을 조회합니다. 이를 통해 특정 시점의 인터페이스 정보를 상세하게 분석할 수 있습니다.

Top 물리서버 목록

전체 물리서버 중 선택된 성능지표의 값이 가장 높은 상위 물리서버를 순위별로 표시합니다. 비율 컬럼은 전체 물리서버의 합산 값에서 개별 물리서버의 값이 차지하는 비율을 의미합니다. 개별 물리서버를 선택하는 경우에는 하단 목록에 선택된 물리서버만 조회되며, 우측의 파이차트에도 해당 물리서버의 영역이 하이라이트 됩니다. 성능지표(전체 트래픽, 전체 초당 연결 수, 전체 현재 세션 수, 전체 패킷)와 목록에 표시할 물리서버의 개수를 변경하여 지표 별 상세 분석이 가능합니다.
