네트워크 자동맵

전체구성에서 \[맵\]을 선택하여 네트워크 자동맵에서 네트워크 데이터의 흐름을 확인할 수 있습니다. 네트워크 자동맵은 최근 5분 동안 에이전트에서 수집한 데이터를 자동으로 시각화하여 노드와 링크로 표시합니다.

<table>
<tbody>
<tr class="odd">
<td><p><img src="./images/network-006/media/image3.png" style="width:0.21667in;height:0.21667in" />노트</p>
<p>네트워크 자동맵에서 표시되는 노드는 [전체구성] 메뉴의 [관리 대상 추가]에서 [관리 대상 등록]을 통해 등록되어야 합니다.</p>
<p>네트워크 자동맵은 Administrators 역할을 가진 계정에게 제공되는 기능이며, 장비 권한 설정에 영향을 받지 않습니다. 장비 권한과 관계없이 노드로 표시할 수 있습니다.</p>
<p>네트워크 자동맵은 커널 버전이 Red Hat Linux 4.18.0-80 이상이고, /sys/kernel/btf 경로에 vmlinux 파일이 있는 경우 지원합니다. (타 OS는 네트워크 자동맵에 표시되지 않습니다.)</p></td>
</tr>

연결 표시

최대 크기 등급에 해당하는 노드를 기준으로 네트워크 자동맵에 표시할 노드 depth를 설정합니다. Depth는 노드와 노드 사이의 연결을 의미하며, depth 계산의 시작점은 최대 크기 등급의 노드입니다. 최대 크기 등급의 노드와 연결된 노드는 1 depth에 해당하며, 1 depth 노드에 연결된 노드는 2 depth가 됩니다. 최대 크기 등급의 노드와 연결이 멀어질수록 depth가 증가합니다. 단, 최대 크기 등급의 노드간의 연결은 depth 계산을 하지 않습니다 (=0 depth). 연결 표시의 기본 설정은 1 depth 표시입니다.

![](./images/network-006/media/image8.png)

▶ \[그림 \] 연결 표시

화면 지표

| 1\. 1 Depth | 최대 크기 등급의 노드와 직접 연결된 노드만 표시합니다.                     |
| ----------- | --------------------------------------------------- |
| 2\. 2 Depth | 1 Depth 노드에 연결된 노드까지 표시합니다.                         |
| 3\. 3 Depth | 2 Depth 노드에 연결된 노드까지 표시합니다.                         |
| 4\. Max     | Depth 계산을 하지 않고 최대 크기 등급 노드를 기준으로 연결된 모든 노드를 표시합니다. |

알람

네트워크 자동맵 노드에 현재 발생한 알람의 표시 여부를 설정합니다. 네트워크 자동맵 화면 접속 시 알람 설정은 비활성화 상태이며, 토글 버튼을 통해 활성화할 수 있습니다. 알람을 활성화하면 상위 3단계 심각도의 알람이 노드에 표시됩니다. 한 노드에 여러 등급의 알람이 발생한 경우, 심각도 등급이 가장 높은 알람이 노드에 표시되며, 심각도 버튼을 클릭하여 해당 심각도 알람 표시 여부를 ON/OFF할 수 있습니다. 만약 최근 5분 사이에 새롭게 발생한 알람이 있다면 노드 알람 표시가 깜박입니다.

범례

네트워크 자동맵에 표시된 노드와 링크의 크기 정보를 표시합니다. 노드와 링크는 데이터 크기에 따라 5단계로 분류됩니다. 범례의 Max 값은 화면에 표시된 노드와 링크 데이터 중 가장 큰 데이터를 의미합니다. 범례는 지표를 선택할 때마다 해당 지표 데이터에 따라 업데이트 됩니다.

노드

네트워크 자동맵에서 각각의 리소스는 노드 형태로 표시됩니다. 노드 위로 마우스 hover하면 노드와 연결된 링크가 하이라이트 되어 노드와 연결된 네트워크가 시각적으로 표현됩니다.

각 노드의 상세 정보는 노드를 클릭하면 호출되는 노드 요약 드로어에서 확인할 수 있습니다. 노드 요약 드로어에서는 각 노드의 IP별 네트워크 데이터, 상태 요약, 알람 현황, 기본 성능 데이터 차트, 이벤트 목록을 제공합니다. 만약 노드와 연결된 상대편 노드(=destination노드)가 POLESTAR에서 관리 중인 장비인 경우, 해당 장비의 기본 성능 데이터도 노드 드로어에서 확인할 수 있습니다. destination 노드가 POLESTAR 관리 장비가 아니더라도 기본 네트워크 성능 지표 정보를 제공합니다.

‘AI 이상감지’ 기능이 활성화되어 있고, AI 아이콘이 표시되어 있는 노드에서는 성능 이상감지 분석 결과도 네트워크 자동맵에서 손쉽게 확인할 수 있습니다.

네트워크 자동맵에서 가장 작은 사이즈의 노드에는 아이콘이 표시되지 않습니다.

네트워크 자동맵 데이터를 수집하지는 않지만 POLESTAR 관리 장비인 경우, 노드 크기에 따라 장비별 대표 아이콘이 노드에 표시되고, 노드 드로어 대신 툴팁을 통해 트래픽 Rx와 트래픽 Rx 데이터량 지표값을 제공합니다. 노드를 클릭해서 해당 장비의 상세 드로어를 확인할 수 있습니다.

링크

링크는 노드와 노드 사이의 네트워크 데이터 흐름을 표시합니다. 링크에 마우스 hover를 하면 해당 링크가 보라색으로 하이라이트 되고 링크의 네트워크 데이터 상세 정보가 툴팁으로 나타납니다. 만약 source 노드와 destination 노드는 동일하지만 연결된 IP 정보가 다른 네트워크 데이터가 여러 건이 있는 다중 링크의 경우, 링크에는 데이터 개수가 표시되고 성능 데이터가 가장 큰 링크 정보가 툴팁에 표시됩니다.

링크 요약 드로어에서 source와 destination 셀렉터를 조합하여 링크의 네트워크 데이터 정보와 상태요약, 프로세스 정보를 확인할 수 있습니다.
