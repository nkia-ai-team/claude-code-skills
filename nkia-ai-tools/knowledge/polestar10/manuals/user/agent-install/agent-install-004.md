사용자 매뉴얼

Polestar 10.2.3

서문

본 제품은 **기업의 핵심 IT 장비 및 서비스**를 통합적으로 관리하기 위한 강력한 도구입니다.

다음과 같은 주요 기능을 제공합니다:

  - **모니터링**: 서버, 네트워크, 데이터베이스(DB), 애플리케이션 성능(APM) 등 다양한 IT 장비와 서비스를 실시간으로 모니터링할 수 있습니다.

  - **알림 관리**: 시스템 장애나 성능 이상이 발생했을 때 신속한 알람을 통해 문제를 조기에 감지하고 대응할 수 있도록 지원합니다.

  - **데이터 분석**: 수집된 데이터를 바탕으로 문제 원인을 분석하고, 성능 최적화를 위한 통찰력을 제공합니다.

  - **사용자 및 권한 관리**: 효율적인 팀 협업과 보안을 위해 사용자 계정과 접근 권한을 체계적으로 관리할 수 있습니다.

본 제품은 IT 운영의 가시성을 높이고, 빠르고 정확한 문제 해결을 지원하며, 안정적인 비즈니스 환경을 유지하는 데 기여합니다.

사용 중 궁금한 점이 생기거나 추가 지원이 필요하면 언제든지 고객 지원 센터로 문의해 주십시오.

문서 개요

본 문서는 IT 인프라 운영관리 솔루션인 Polestar 10(“Polestar”) 사용자를 위하여 작성된 사용자 매뉴얼입니다.

본 문서에는 Polestar의 주요 기능을 이용하는 방법들을 화면 예시와 함께 자세하게 설명되어 있습니다.

본 문서는 Polestar 사용자를 위한 사용자 매뉴얼이며, Polestar 설치 등의 내용은 Polestar 관리자 매뉴얼을 참조하시기 바랍니다.

본 매뉴얼에 예시된 화면과 기능 설명은 제품의 기능 안정화와 성능 향상에 따라 사전 예고 없이 변경될 수 있습니다.

변경된 내용은 별도의 문서를 통하여 고객사에게 그 내용을 통지하거나 (주)엔키아의 홈페이지를 통하여 고지되며, 본 문서의 차기 재개정 시 반영될 것입니다.

변경된 제품은 (주)엔키아와 고객사가 맺은 계약 내용에 따라 무상 또는 유상으로 지원됩니다.
