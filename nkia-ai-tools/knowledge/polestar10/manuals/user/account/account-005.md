기본 사용자 정의 항목 관리

서버 등록 시 자동으로 등록되는 사용자 정의 항목을 관리합니다. 로그, 윈도우 이벤트 로그, 프로세스, 파일, 윈도우 서비스를 지원하며, OS별로 등록할 사용자 정의 항목을 설정합니다.

로그

\[로그\] 탭을 선택하여 서버 등록 시 자동으로 등록되는 기본 로그 정의를 관리할 수 있습니다.

로그 추가

서버에서 기본적으로 관리하는 로그 정의를 등록합니다. 로그 정의 추가 시 설정하는 정보는 서버에서 사용자 정의 항목 중 로그를 등록할 때와 동일하며, ‘설정 정보 적용 여부’ 항목으로 기본 로그 적용 여부를 설정할 수 있습니다. ‘설정 정보 적용 여부’가 체크되어 있는 로그 정의는 지정한 OS에 해당하는 서버가 등록될 때 자동으로 등록되며, 등록 직후부터 모니터링을 진행합니다.

로그 추가 절차

 

1.  로그 목록 우측 상단의 \[추가\] 버튼 클릭

2.  추가할 로그 정보를 입력하고 \[저장\] 버튼 클릭

로그 수정

로그 목록에서 ‘이름’ 필드를 클릭하여 등록된 로그 정의를 수정할 수 있습니다. 수정된 로그 정의는 ‘설정 정보적용 여부’가 활성화되어 있으면 ‘일괄적용’ 기능을 통해 서버에 등록되어 있는 로그에 적용됩니다. 신규 추가하는 서버에는 수정된 로그 정보가 적용됩니다.

![](./images/account-005/media/image4.png)

▶ \[그림3\] 로그 상세

로그 수정 절차

 

1.  로그 목록에서 수정할 로그 정보의 ‘이름’ 필드 클릭

2.  로그 정보를 수정하고 \[저장\] 버튼 클릭

로그 삭제

로그 목록에서 특정 로그 정의를 삭제할 수 있습니다. 로그 정의를 삭제하더라도 서버에 등록된 로그에는 영향을 미치지 않습니다.

![](./images/account-005/media/image5.png)

▶ \[그림4\] 로그 삭제

로그 삭제 절차

 

1.  로그 목록에서 삭제할 로그 정의 선택 (다수 선택 가능)

2.  로그 목록 우측 상단의 \[삭제\] 버튼 클릭

로그 일괄적용

‘일괄적용’ 기능을 통해 선택한 로그 정의를 등록된 서버에 반영할 수 있습니다. 일괄적용 기능은 백그라운드 작업으로 진행되므로 기능 실행 후 다른 메뉴 화면으로 이동하더라도 정상적으로 적용됩니다.

일괄적용 기능은 선택한 로그 정의가 서버에 등록되어 있지 않으면 신규 로그로 등록합니다. 서버에 로그가 이미 등록되어 있고, 기본 사용자 정의 항목 관리의 로그 정의 설정이 업데이트 된 경우에는 등록되어 있는 로그가 기본 사용자 정의 항목 관리 설정으로 업데이트 됩니다. 단, 기본 사용자 정의 항목 관리의 로그 정의 설정이 업데이트 된 이후에 사용자가 서버에 등록된 로그를 직접 업데이트한 경우에는 사용자의 설정 내용이 우선시되며, 기본 사용자 정의 항목 관리의 로그 정의 설정이 적용되지 않습니다.

![](./images/account-005/media/image6.png)

▶ \[그림5\] 로그 일괄적용

로그 일괄적용 절차

 

1.  로그 목록에서 일괄적용할 로그 정의 선택 (다중 선택 가능)

2.  로그 목록 우측 상단의 \[일괄 적용\] 버튼 클릭

3.  일괄적용 팝업창 내용 확인 후 \[확인\] 버튼 클릭

4.  일괄적용 시작 안내 팝업창 확인

1.  파일 목록에서 삭제할 파일 정의 선택 (다수 선택 가능)

2.  파일 목록 우측 상단의 \[삭제\] 버튼 클릭

파일 일괄적용

‘일괄적용’ 기능을 통해 선택한 파일 정의를 등록된 서버에 반영할 수 있습니다. 일괄적용 기능은 백그라운드 작업으로 진행되므로 기능 실행 후 다른 메뉴 화면으로 이동하더라도 정상적으로 적용됩니다.

일괄적용 기능은 선택한 파일 정의가 서버에 등록되어 있지 않으면 신규 파일로 등록합니다. 서버에 파일이 이미 등록되어 있고, 기본 사용자 정의 항목 관리의 파일 정의 설정이 업데이트 된 경우에는 등록되어 있는 파일이 기본 사용자 정의 항목 관리 설정으로 업데이트 됩니다. 단, 기본 사용자 정의 항목 관리의 파일 정의 설정이 업데이트 된 이후에 사용자가 서버에 등록된 파일을 직접 업데이트한 경우에는 사용자의 설정 내용이 우선시되며, 기본 사용자 정의 항목 관리의 파일 정의 설정이 적용되지 않습니다.

▶ \[그림20\] 파일 일괄적용

파일 일괄적용 절차

 

1.  파일 목록에서 일괄적용할 파일 정의 선택 (다중 선택 가능)

3.  일괄적용 팝업창 내용 확인 후 \[확인\] 버튼 클릭

4.  일괄적용 시작 안내 팝업창 확인

윈도우 서비스

\[윈도우 서비스\] 탭을 선택하여 서버 등록 시 자동으로 등록되는 기본 윈도우 서비스 정의를 관리할 수 있습니다.

![](./images/account-005/media/image22.png)

▶ \[그림21\] 윈도우 서비스 목록

화면 지표

| OS     | 윈도우 서비스가 적용될 서버의 OS 종류를 표시합니다. |
| ------ | ------------------------------ |
| 이름     | 윈도우 서비스 정의 이름을 표시합니다.          |
| 서비스 이름 | 모니터링할 윈도우 서비스의 이름을 표시합니다.      |
| 적용 여부  | 서버 적용 여부를 표시합니다.               |

윈도우 서비스 추가

서버에서 기본적으로 관리하는 윈도우 서비스 정의를 등록합니다. 윈도우 서비스 정의 추가 시 설정하는 정보는 서버에서 사용자 정의 항목 중 윈도우 서비스를 등록할 때와 동일하며, ‘설정 정보 적용 여부’ 항목으로 기본 윈도우 서비스 적용 여부를 설정할 수 있습니다. ‘설정 정보 적용 여부’가 체크되어 있는 윈도우 서비스는 윈도우 OS 서버가 등록될 때 자동으로 등록되며, 등록 직후부터 모니터링을 진행합니다.

▶ \[그림22\] 윈도우 서비스 추가

기본 정보

| 이름          | 등록할 윈도우 서비스 정의 이름을 입력합니다.     |
| ----------- | ----------------------------- |
| 설명          | 등록할 윈도우 서비스에 대한 설명을 입력합니다.    |
| 설정 정보 적용 여부 | 등록할 윈도우 서비스의 서버 적용 여부를 설정합니다. |

설정 정보

|        |                          |
| ------ | ------------------------ |
| 서비스 이름 | 모니터링할 윈도우 서비스 이름을 설정합니다. |

윈도우 서비스 추가 절차

 

1.  윈도우 서비스 목록 우측 상단의 \[추가\] 버튼 클릭

2.  추가할 윈도우 서비스 정보를 입력하고 \[저장\] 버튼 클릭

윈도우 서비스 수정

윈도우 서비스 목록에서 ‘이름’ 필드를 클릭하여 등록된 윈도우 서비스 정의를 수정할 수 있습니다. 수정된 윈도우 서비스 정의는 ‘설정 정보 적용 여부’가 활성화되어 있으면 ‘일괄적용’ 기능을 통해 서버에 등록되어 있는 윈도우 서비스에 적용됩니다. 신규 추가하는 서버에는 수정된 윈도우 서비스 정보가 적용됩니다.
