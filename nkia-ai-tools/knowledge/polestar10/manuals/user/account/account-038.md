| 1\. 대시보드 타이틀 | 대시보드의 타이틀을 표시합니다. 더블 클릭 시 타이틀을 변경할 수 있습니다. |
| ------------ | ------------------------------------------ |
| 2\. 페이지 이름   | 페이지 이름을 표시합니다. 더블 클릭 시 이름을 변경할 수 있습니다.     |
| 3\. 페이지 추가   | 신규 페이지를 추가할 수 있습니다.                        |

| 6\. 위젯 크기 변경 | 클릭 후 드레그 하여 위젯의 크기를 변경할 수 있습니다.            |

위젯 대시보드 레이아웃

위젯 대시보드의 구성을 손쉽게 하기위해 레이아웃을 선택할 수 있습니다. 4가지의 시각화 레이아웃과 자유형태의 레이아웃이 있습니다. 사용자는 선택한 레이아웃을 이용하여 다양한 위젯 대시보드를 생성할 수 있습니다.

![](./images/account-038/media/image5.png)

▶ \[그림2\] 위젯 대시보드 레이아웃

개별 메뉴

| 1\. 균형형 대시보드  | 레이아웃은 균등하고 대칭적인 위젯 배치를 통해 데이터를 효과적으로 정리하고 비교할 수 있도록 합니다.               |
| ------------- | ---------------------------------------------------------------------- |
| 2\. 강조형 대시보드  | 데이터의 중요도에 따라 위젯 크기를 달리하여 주요 정보를 효과적으로 전달하는 데 최적화되어 있습니다.               |
| 3\. 계층형 대시보드  | 계층적이고 유연한 정보 배치를 통해 다양한 데이터 유형을 효과적으로 시각화할 수 있습니다.                     |
| 4\. 분할형 대시보드  | 작은 위젯과 큰 위젯의 조합으로 시각적 균형 유지와 데이터 비교 용이하여 중요한 데이터의 세부 정보를 한눈에 볼 수 있습니다. |
| 5\. 지유형태 레이아웃 | 사용자 선호에 따라 대시보드를 개인화하여 효율적인 정보 접근과 분석을 지원합니다.                          |

► \[그림6\] 대상 선택 설정

화면 설명

| 1\. 필터    | 대상 선택에서 선택한 필터를 표시합니다. 리소스를 선택할 경우 관리대상 필터가 추가됩니다.              |
| --------- | --------------------------------------------------------------- |
| 2\. 관리 대상 | 필터에 포함된 관리 대상을 표시합니다. 관리 대상을 클릭하면 선택할 수 있으며 다시 클릭하면 해제할 수 있습니다. |
| 3\. 대상 변경 | 현재 설정된 대상 정보를 변경합니다.                                            |

페이지 추가

위젯 대시보드의 페이지는 \[새 페이지 추가\]를 눌러 신규 페이지를 추가할 수 있습니다.

![](./images/account-038/media/image10.png)

► \[그림7\] 페이지 추가

페이지 관리

설정 메뉴에서 \[페이지 관리\]를 팝업 할 수 있습니다. \[페이지 관리\] 화면에서는 페이지의 리스트를 확인할 수 있으며 이름을 수정할 수 있습니다. 슬라이드 설정을 통하여 슬라이드 쇼를 지원합니다.

![](./images/account-038/media/image11.png)

► \[그림8\] 페이지 관리

페이지 복제

설정 메뉴에서 \[복제\]를 선택하여 선택 중인 페이지를 복제할 수 있습니다. 선택 된 페이지의 모든 구성요소를 복제합니다. 복제된 페이지는 이름 뒤에 -Copied 가 붙습니다.

![](./images/account-038/media/image12.png)

템플릿 대시보드를 이용하여 간단한 조작만으로 완성형 대시보드를 생성할 수 있습니다. 완성형 대시보드를 생성할 수 있는 방법은 여러가지가 있으며 \[신규 대시보드 생성\], 템플릿 대시보드 상세에서 \[템플릿 사용\], 템플릿 개별 메뉴에서 \[템플릿으로 대시보드 생성\] 총 3가지의 방법을 제공합니다.

완성형 대시보드 생성

완성형 대시보드의 생성은 3개의 STEP로 진행되며 각 STEP 은 간단한 클릭과 확인으로 진행됩니다. STEP 1은 템플릿 선택이며 등록된 템플릿에서 원하는 위젯 대시보드를 선택합니다. STEP 2은 대상 선택이며 특정 대상을 위한 대시보드를 설정할 경우 원하는 대상을 설정하고 다음으로 넘어갑니다. 만약 전체 대상으로 할 경우 대상을 선택하지 않고 다음으로 넘어갑니다. STEP3 은 설정 완료이며 최종적으로 확인할 정보를 표시하며 간단한 스켈레톤 형식의 미리보기를 지원합니다. 이후 \[대시보드 생성\] 을 클릭하면 완성된 위젯 대시보드가 팝업됩니다.
