사용자 관리

운영관리를 선택하면 사용자 관리 화면을 확인할 수 있습니다.

사용자 관리 화면은 \[계정\], \[그룹\], \[역할\] 총 3개의 탭으로 구성되어 있습니다.

1.  테이블 우측 상단의 (+) 아이콘 클릭

4.  \[저장\] 버튼 클릭

계정 수정 절차

1.  테이블에서 수정할 계정 클릭

2.  기본 설정 항목 입력

3.  \[비밀번호 변경\] 버튼을 클릭해 신규 비밀번호를 입력

4.  \[비밀번호 변경\] 버튼을 클릭해 비밀번호 변경

5.  역할/그룹 선택

6.  \[저장\] 버튼 클릭

▶ 사용자 일괄 등록

화면 지표

| 템플릿 다운로드    | 일괄 등록 템플릿을 다운로드합니다.        |
| ----------- | -------------------------- |
| 등록된 설정 다운로드 | 등록된 데이터를 다운로드합니다.          |

사용자 일괄 등록 절차

1.  파일 업로드

2.  업로드 설정 목록에서 결함 확인

3.  결함이 없으면 저장 버튼 클릭
