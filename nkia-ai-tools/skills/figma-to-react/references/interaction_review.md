# Interaction Review (Step 8.5)

## 목적

QA Phase를 통과한 후, Step 1.6에서 **추론(inferred)**으로 생성한 인터랙션을
사용자와 확인하여 최종 코드를 완성한다.

## 실행 조건

- Step 1.6에서 신뢰도가 "추론" 또는 "기획 기반"인 항목이 1개 이상: 이 Step 실행
- 모든 항목이 "확인됨" (프로토타입 연결 기반): 이 Step **스킵**
- Step 1.6에서 interactions가 0개여서 건너뛴 경우: 이 Step 실행 (사용자에게 인터랙션 질문)

## 8.5-1. 사용자에게 인터랙션 확인 질문

추론된 인터랙션을 표로 보여주고 사용자에게 확인한다.

    ## Interaction Review: {컴포넌트/화면명}

    아래 인터랙션은 디자인 구조에서 추론했습니다. 확인해주세요.

    ### 확인 필요 항목
    | # | 유형 | 소스 | 추론 내용 | 맞습니까? |
    |---|------|------|----------|----------|
    | 1 | Navigation | "도구" 버튼 | 클릭 → 도구 화면 이동? | Y / N / 수정 |
    | 2 | Overlay | "설정" 아이콘 | 클릭 → 설정 모달 열기? | Y / N / 수정 |
    | 3 | State | Log 컴포넌트 | 클릭 → 접기/펼치기 토글? | Y / N / 수정 |

    ### 추가 인터랙션
    위 목록에 빠진 인터랙션이 있으면 알려주세요.
    - 예: "알람분석 메뉴 클릭 → 알람 선택 컴포넌트 표시"

## 8.5-2. 사용자 응답 반영

    응답 처리:
    - Y (확인): 추론 그대로 유지, 신뢰도를 "확인됨"으로 변경
    - N (부정): 해당 인터랙션 제거, 관련 코드 제거
    - 수정: 사용자가 제공한 내용으로 수정, 코드 반영
    - 추가: 새 인터랙션 추가, 코드 생성

    코드 수정 범위:
    - Navigation/Overlay 핸들러 추가/제거/수정
    - useState 추가/제거
    - import 추가/제거
    - JSX에 이벤트 핸들러 연결/해제

## 8.5-3. 인터랙션 0개 (프로토타입 미설정) 시 대화

프로토타입 연결이 전혀 없는 경우, 핵심 인터랙션을 사용자에게 질문한다.

    ## Interaction Review: {화면명}

    이 화면에 Figma 프로토타입 연결이 없어서 인터랙션을 자동 추출할 수 없었습니다.
    디자인 구조에서 아래 요소들이 인터랙션 후보로 보입니다:

    ### 인터랙션 후보 (구조 추론)
    | # | 요소 | 추론 근거 | 동작 추론 |
    |---|------|----------|----------|
    | 1 | 사이드바 메뉴 아이템 | 클릭 가능한 리스트 | 클릭 → 해당 화면 이동? |
    | 2 | "새 대화" 버튼 | 버튼 컴포넌트 | 클릭 → 대화 초기화? |
    | 3 | collapse 아이콘 | 토글 버튼 | 클릭 → 사이드바 접기? |

    각 요소의 동작을 알려주시면 코드에 반영하겠습니다.
    또는 넘어가셔도 됩니다 — 나중에 별도로 인터랙션을 추가할 수 있습니다.

## 8.5-4. 반복 루프

사용자 응답 → 코드 수정 → 추가 질문이 있으면 반복.
사용자가 "완료" 또는 "넘어가기"라고 하면 Step 9로 진행.

    루프 제한: 없음 (사용자 주도)
    단, 매 수정 후 간단한 확인을 출력:
    "인터랙션 {N}개 확정, 코드 반영 완료. 추가 수정이 있으면 알려주세요."
