# Auto Mode Workflow

자연어로 추가 작업을 설명하면 자동으로 DoD/AC 업데이트를 추천합니다.

---

## Step 1: Fetch Current Issue

`mcp__linear__get_issue`를 사용하여 현재 이슈 정보와 기존 DoD/AC를 가져옵니다.

```
=== 현재 이슈 정보 ===

제목: code-review 및 commit 스킬 Linear 이슈번호 형식 적용
상태: In Progress

현재 DoD:
1. [ ] code-review 스킬 브랜치명 검증 패턴 수정 → 결과물: PR 링크
2. [ ] commit 스킬 커밋 메시지 형식 수정 → 결과물: PR 링크

현재 AC:
1. [ ] feature/nkiaai-XXX 브랜치명 인식 → 결과물: 테스트 결과
2. [ ] nkiaai-XXX Feat : 형식 커밋 메시지 생성 → 결과물: 테스트 결과

=======================
```

## Step 3: Analyze and Generate Suggestions

LLM이 자연어 입력과 현재 이슈 맥락을 분석하여 DoD/AC 추가/수정 사항을 추천합니다.

**분석 기준:**
1. **새로운 작업 식별**: 자연어에서 새로 해야 할 작업 추출
2. **기존 항목 연관성**: 현재 DoD/AC와 중복되거나 확장되는 내용 확인
3. **적절한 분류**: DoD(프로세스 완료)와 AC(품질 기준) 구분
4. **결과물 정의**: 각 항목의 검증 가능한 결과물 제안

**추천 항목 JSON 형식:**
```json
{
  "analysis": {
    "summary": "GitLab 대용량 파일 처리 기능 추가 필요",
    "related_existing": ["DoD #1 - code-review 스킬 수정에 포함 가능"]
  },
  "suggestions": {
    "add_dod": [
      {
        "content": "GitLab 대용량 파일 전체 조회 로직 구현",
        "evidence": "PR 링크 {{pr_link}}",
        "priority": null,
        "reason": "diff가 잘릴 때 별도 API로 파일 내용 조회 필요"
      }
    ],
    "add_ac": [
      {
        "content": "500줄 이상 파일 전체 내용 조회 가능",
        "evidence": "MR 리뷰 결과 {{review_link}}",
        "priority": "[필수]",
        "reason": "대용량 파일도 리뷰 가능해야 함"
      },
      {
        "content": "리뷰 결과에 '📦 대용량 파일' 표시",
        "evidence": "리뷰 코멘트 스크린샷 {{screenshot}}",
        "priority": null,
        "reason": "사용자에게 대용량 파일임을 명시"
      }
    ],
    "modify_dod": [],
    "modify_ac": []
  }
}
```

## Analysis Guidelines

### 작업 유형별 추천 패턴

**코드 변경 작업:**
- DoD: 코드 구현, PR 생성, 코드 리뷰
- AC: 기능 동작 확인, 테스트 통과, 성능 기준

**버그 수정 작업:**
- DoD: 원인 분석, 수정 코드, 재발 방지 테스트
- AC: 재현 불가 확인, 관련 에러 0건

**문서 작업:**
- DoD: 문서 작성, 리뷰 완료
- AC: 필수 섹션 포함, 예시 코드 동작 확인

**설정/배포 작업:**
- DoD: 설정 파일 수정, 배포 완료
- AC: 환경 정상 동작, Healthcheck 통과

### 결과물 추천 규칙

| 작업 유형 | 추천 결과물 |
|----------|-----------|
| 코드 작업 | PR 링크, 테스트 결과 |
| 문서 작업 | 문서 링크, 리뷰 기록 |
| 배포 작업 | 배포 로그, Healthcheck 결과 |
| 데이터 작업 | 데이터 경로, 품질 리포트 |
| 리서치 작업 | 조사 문서, 결론 요약 |

### 기존 항목 연관성 분석

자연어 입력을 분석할 때 기존 DoD/AC와의 관계를 파악합니다:

1. **확장 관계**: 기존 항목을 더 구체화하거나 세분화
2. **의존 관계**: 기존 항목이 선행되어야 하는 경우
3. **독립 관계**: 기존 항목과 별개의 새로운 작업
